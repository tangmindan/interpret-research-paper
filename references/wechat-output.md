# Accessible and WeChat literature articles

Read this only when the user requests a WeChat or accessible long-form article.

- Create a separate artifact; do not overwrite the deep-reading note by default.
- Build a connected narrative for an educated non-specialist or life-science audience rather than copying note bullets and callouts.
- Preserve exact key numbers, figure order, scientific uncertainty, and evidence boundaries while simplifying mechanics.
- Introduce the field problem and research question before methods. Treat design figures as orientation and result figures as question → strategy → evidence → conclusion → boundary.
- Avoid clickbait, poster slogans, exaggerated headings, childish analogies, and unsupported clinical or causal claims.
- Use only visually verified figures and derive portable paths from resolved configuration.
- End with the paper citation and relevant data/code links.
